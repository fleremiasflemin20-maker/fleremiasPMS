## Sobre el proyecto

Landing page comercial de **Fleremahias PMS**, un sistema de gestión hotelera pensado específicamente para el mercado ecuatoriano: facturación electrónica integrada con el SRI, funcionamiento en modo offline y gestión completa del hotel desde cualquier dispositivo.

El producto completo (panel web, API y apps móviles) vive en repositorios separados:

- [`fleremias-pms`](https://github.com/fleremiasflemin20-maker/fleremias-pms) — panel de gestión (front desk, reservas, housekeeping, facturación)
- [`fleremias-api`](https://github.com/fleremiasflemin20-maker/fleremias-api) — backend
- [`fleremias-staff`](https://github.com/fleremiasflemin20-maker/fleremias-staff) · [`fleremias-admin-mobile`](https://github.com/fleremiasflemin20-maker/fleremias-admin-mobile) · [`fleremias-guest`](https://github.com/fleremiasflemin20-maker/fleremias-guest) — apps móviles

## Tecnologías

- **HTML5** · **Tailwind CSS** (CDN)
- **Google Fonts** (Manrope, Inter) + **Material Symbols**
- Diseño responsive, listo para producción estática (GitHub Pages)

## Ver el código localmente

```bash
git clone https://github.com/fleremiasflemin20-maker/fleremiasPMS.git
cd fleremiasPMS
```

Abre `index.html` directo en el navegador — no requiere build ni instalación.
